## Project Overview

The Attendance Tracker is a simple application designed to record and manage student attendance. It helps teachers mark students as present or absent and view attendance records.

## Objectives

* Maintain student attendance records.
* Mark students as present or absent.
* View attendance information easily.
* Calculate student attendance percentages.

## Main Features

1. View the student list.
2. Mark attendance.
3. View attendance records.
4. Calculate attendance percentages.
